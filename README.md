# Dice Race Game

## About the Project

This project is a simple **dice racing game** developed with **Python**.
The game is created using **Turtle** for graphics and **Tkinter** for the user interface.

In this game, three players move on a race path. The movement of each player depends on the random number generated by the dice. The first player who reaches the finish point wins the game.

## How the Game Works

* The game has three players:

  * Red player
  * Green player
  * Blue player

* Players take turns rolling the dice.

* The dice generates a random number between 1 and 6.

* The player moves according to the dice number.

* Players follow the path until one of them reaches the final point.

* The first player who reaches the finish point is the winner.

## Features

* Three-player racing system
* Graphical game board
* Random dice number generation
* Turn-based gameplay
* Player movement animation
* Winner detection

## Technologies Used

* Python
* Turtle Library
* Tkinter Library
* Random Library

## How to Run

1. Install Python.
2. Download or clone the project.
3. Run the main Python file.
4. Start the game and roll the dice.
